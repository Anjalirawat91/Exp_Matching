Regular Expression Matcher

Match strings using the + operator

About the Problem

Given an input string and a pattern, check whether the pattern matches the entire input string.

The + operator means one or more occurrences of the preceding character.

Example:
String: AAAB
Pattern: A+B
Result: True

Test Your Pattern

Result

Enter a string and pattern to check.

Supported Pattern

+
One or more occurrences

The plus symbol means that the character before it must appear at least once.

A+ → A, AA, AAA...
A+B → AB, AAB, AAAB...
AB+ → AB, ABB, ABBB...

How It Works

  1. Read the input string and pattern.
  2. Check whether the pattern has valid syntax.
  3. Process each character of the pattern.
  4. If + is present, match one or more occurrences of the previous character.
  5. Check whether the complete input string is matched.
  6. Return True or False.
